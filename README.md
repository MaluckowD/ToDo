# ToDo — умный календарь для управления задачами 📅✅  

**ToDo** — это современное веб-приложение для планирования, которое помогает организовать вашу работу и личные дела с максимальной эффективностью.  

## 🔐 Система безопасности и аккаунт  
- **Полноценная регистрация** с подтверждением email  
- **Авторизация** через email/пароль
- **Загрузка аватарки** (поддержка JPG/PNG/WEBP)  
- **Редактирование профиля** (имя, пароль)  

## 📝 Основные функции задач  
- **Создание задач** с заголовком, описанием и дедлайном  
- **Категории задач** (работа, дом, учеба) с цветовой маркировкой  
- **2 статуса выполнения**:  
  - 🟢 Выполнено
  - 🔴 Не выполнено   
- **Гибкое редактирование**:  
  - Перемещение между днями drag&drop  
  - Быстрое изменение статуса  
  - Полное удаление задач  

## 🗓 Работа с календарем  
- Дневной/недельный/месячный режим просмотра  
- Быстрая навигация по датам  
- Цветовые метки по приоритетам  

## 🔔 Дополнительные возможности  
- Мобильная адаптация  

## 🛠 Технологический стек  
- **Frontend**: React + Zustand + TypeScript  

## 🚀 Как начать использовать  
1. Зарегистрируйтесь
2. Подтвердите email (письмо придет в течение 5 минут)  
3. Настройте профиль и загрузите аватар  
4. Создайте первую задачу!
